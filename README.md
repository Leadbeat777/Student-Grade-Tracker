# Student-Grade-Tracker
Student Grade Tracker Overview Student Grade Tracker is a Python application that processes student assessment data from CSV format, calculates averages, assigns letter grades, handles invalid or missing scores, and exports results to JSON. 

Features
Reads student records from CSV data
Safely handles missing or invalid scores
Calculates averages from valid scores only
Assigns letter grades automatically
Generates a formatted report
Exports processed results as JSON
Requirements
Python 3.8 or newer
No external packages are required.

Installation
Clone the repository:
git clone https://github.com/yourusername/student-grade-tracker.git

Move into the project directory:
cd student-grade-tracker

Usage
Run the application:

python student_grade_tracker.py
